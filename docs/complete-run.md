# 一局闭环（已冻结规格）

> 2026-08-20 确认。目标：红糖云服横屏上能打完、能重开的一局，不是内容大全、不是上架清单。  
> 约束：约 2 周、单人、每周 6–8 小时（一共约 12–16 小时）。超时先砍后半波权重微调，不砍胜负和再来。  
> 实现工单：`.scratch/complete-run/issues/`（一票一个文件，按 Blocked by 做前沿）。

规格本身不要在实现中途改；要改先更新本文件「已冻结」一节。勾选进度可与工单对照，以工单验收为准。

---

## 已冻结

### 交付

- 任意 5 个角色 + 任意 I 阶武器，认真打第一次应能通关（按 15 血的全能/狂人平衡；骑士更肉是角色差异）。
- 一局约 6–8 分钟；有胜利、有失败、能再来。
- 只做红糖云服横屏小程序。包名仍为 `Brotato`，这两周不改。

### 节奏

- 8 波，每波战斗 30 秒，出怪间隔仍约 0.8 秒。
- 第 1–7 波结束：清怪 → 选 1 张升级 → 商店 → 下一波（保持现有循环，不加经验条）。
- 第 8 波倒计时结束且玩家仍活着 → 直接胜利，不再升级、不再进商店。
- 赢 = 撑过第 8 波的表；到点仍按现有逻辑清场，不改成「必须杀光才算」。

### 失败 / 再来

- 死亡不能只 `queue_free` 玩家。
- 失败：「失败」+ 死于第 x 波 +「再来一局」。
- 胜利：「胜利」+「再来一局」。都不显示金币、击杀数。
- 「再来一局」回到选角色和武器（仍须两者都选才能 Continue）。
- 必须重置：金币、已装备武器/被动、波次、场上单位，以及敌人 `.tres` 上被逐波改写的血伤。

### HUD

- 文案：「第 x / 8 波」+ 本波剩余秒数。
- 底下 8 个点：已完成的波点亮，当前波有区别（高亮），未到的波暗。
- 升级/商店期间冻结。第 8 波胜利时 8 个点都亮。

### 经济

- 开局金币 20。
- 不削弱 `gold_drop`。30 秒波次后第一家店会比较阔；商店是强化幻想，不是生存枷锁。

### 敌人与难度

- 每波血/伤成长基本砍掉（调成 0 或接近 0）。
- 1–4 波：只有三种追击者。
- 5–6 波：加入少量冲锋者。
- 7–8 波：再加少量射手（最后一波两种都有，权重低）。
- 后半波变化来自新种类和略提高快速追击者权重，单下伤害不能秒 15 血。

### 必须修的循环漏洞

- 已装备 6 把武器时，仍能买被动；不能买第 7 把武器。
