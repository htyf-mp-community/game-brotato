## 已冻结

### 交付

- 红糖云服横屏。摇杆仍是左半屏浮动（按下出现，圈内跟手指）。
- 战斗 HUD 仍是：左上金币、顶中波次+秒数+8 个点、右上暂停、右下冲刺。
- 选角 / 升级 / 商店 / 暂停层 / 结算 **不换皮**。

### 摇杆

- 外圈半径 110、内钮 42、死区 0.12：**不改**。
- 不改成左下固定摇杆，不做手指出圈后底盘跟着走的动态摇杆。
- 圈和钮大约再淡一半；按下时内钮仍能看清。
- 热区：右半屏本来没有摇杆。左半屏里，金币、波次文字、秒数、点所在的**整条顶栏**内按下，不出现摇杆。用这些控件的包围盒并集，不要写死一个魔法像素。
- 暂停、冲刺的位置和尺寸不改。

### 冲刺与暂停

- 冲刺仍右下、160×160，底大约再淡一半，字仍能认。
- 暂停仍右上约 96×96，不改大小、位置、透明度。

### 波次 HUD

- 「第 x / 8 波」和秒数：字号仍 64，加深色描边。
- 不加顶栏半透明大横条。
- 金币、8 个点：不动。

### 真机过线

- 横屏至少打一波（不要求打满 8 波）。
- 摇杆能跟手；顶栏上按下不会出摇杆。
- 不误触暂停 / 冲刺。
- 波次和秒数看得清。
