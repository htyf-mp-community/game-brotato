> 2026-08-20 确认。上一期「能打完的一局」真机已过。这一期只补壳：战斗中能停、能关声音、能放弃回选角。  
> 约束：约 2 周、单人、每周 6–8 小时（一共约 12–16 小时）。超时先砍选角上的静音入口（本来就不做），不砍暂停按钮、冻波次时间和「放弃本局」。  
> 实现工单：`.scratch/pause-shell/issues/`（一票一个文件，按 Blocked by 做前沿）。

## 已冻结

### 交付

- 红糖云服横屏小程序。包名仍为 `Brotato`，不改。
- 战斗中能暂停、能开关音乐/音效、能放弃本局回到选角。
- 不新增标题页；选角仍是大厅。不做教程、不做独立设置页。

### 入口

- 启动仍进 `arena.tscn` 选角。结算「再来一局」仍回选角。

### 暂停（仅战斗）

- 仅当：场上有活着的玩家，且选角 / 升级 / 商店 / 结算都未打开。
- 右上角约 96×96 的「暂停」按钮；打开暂停层后隐藏该按钮。
- 点开后：玩法停、摇杆和冲刺隐藏、**波次倒计时和出怪计时都停**（现有 `Global.game_paused` 不够，必须把 `WaveTimer` / `SpawnTimer` 也停）。
- 暂停层按钮：继续、音乐开/关、音效开/关、放弃本局。
- 「放弃本局」先二次确认（「确定放弃？」+ 确定 / 取消）。取消回到暂停层。确定后走现有再来重置：回选角，金币、装备、波次、场上单位、敌人血伤清掉。**不是失败结算**，不显示「死于第 x 波」。
- 战斗中宿主报进入后台 → 自动打开同一张暂停层；回前台仍停着，必须点「继续」。只用 SDK 生命周期回调，不接到出怪、伤害、商店。

### 音频

- 音乐、音效两个开关，默认都开。只把这两项写入本地（不是进度存档）。启动时就生效，含选角时的 BGM。
- 选角没有静音开关。关掉后若回到选角，要再进战斗并打开暂停才能打开声音。
- 暂停层打开时 BGM 停；点继续且音乐开关仍开则再播。
- 音效关 = 所有 SFX（含 UI 点击）都不出。

### 必须冻的计时

- 暂停期间第 x / 8 波的秒数和 8 个点保持暂停瞬间的样子（现有 HUD 在 `game_paused` 时已经不刷新点）。

## 实现清单

主场景：`scenes/arena/arena.tscn`  
暂停：`Global.game_paused`、`scenes/arena/spawner.gd` 的 Timer  
音效：`autoloads/sound_manager.gd`、`MusicPlayer`  
选角重置：`arena._return_to_selection()`  
宿主：`_HTYF_SDK/htyf_sdk.gd` 的 `set_host_lifecycle_callback` / `lifecycle` 推送（`event` 与 Godot `NOTIFICATION_APPLICATION_*` 对齐；默认 2017 = paused）

### 1. 战斗暂停

- [x] 仅战斗中显示右上角「暂停」
- [x] 点开暂停层：继续、音乐、音效、放弃本局（后三项可先占位，但层必须能关上）
- [x] 「继续」恢复玩法、摇杆、波次/出怪计时
- [x] 暂停期间波次秒数不再往下走
- [x] 升级 / 商店 / 选角 / 结算时没有暂停按钮

### 2. 静音

- [ ] 音乐、音效开关写入本地，杀进程再开仍在
- [ ] 启动时按配置决定 BGM 是否播放
- [ ] 暂停打开时 BGM 停；继续且音乐开则再播
- [ ] 音效关闭后打击、开火、UI 都不出声

### 3. 放弃本局

- [ ] 「放弃本局」要确认；取消仍停在暂停层
- [ ] 确定后回选角，状态与「再来一局」相同，不走失败 UI

### 4. 后台自动暂停

- [ ] 战斗中收到宿主进入后台 → 打开同一张暂停层
- [ ] 回前台不会自动继续
- [ ] 编辑器失焦/暂停通知尽量走同一套打开暂停的入口，方便 F5 验

### 5. 验收

- [ ] 编辑器：打到一半点暂停，秒数停；继续后接着打
- [ ] 放弃本局 → 选角 → 能重新开打
- [ ] 关掉音乐杀进程再开，选角时 BGM 仍静音
- [ ] 红糖云服真机：切到后台再回来，仍停在暂停层，点继续才动
