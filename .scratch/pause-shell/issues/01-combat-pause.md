# 01: 战斗中能暂停、能继续

**What to build:** 战斗中右上角出现够大的「暂停」。点开后玩法停、摇杆和冲刺隐藏、波次倒计时和出怪计时都停，出现暂停层。点「继续」恢复。选角、升级、商店、结算时不显示暂停按钮。暂停层上可以先摆上音乐/音效/放弃本局，这一票只要求「继续」可用。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 仅战斗中（有活玩家，且选角/升级/商店/结算都没开）显示右上角约 96×96 的「暂停」
- [x] 点开后该按钮隐藏，出现暂停层，玩法停、虚拟摇杆和冲刺隐藏
- [x] 暂停期间 HUD 秒数不再减少，出怪也不再刷
- [x] 「继续」后战斗、摇杆、计时恢复，暂停按钮回来
- [x] 升级/商店/选角/结算过程中点不到暂停
