# 03: 后半波出现冲锋者和射手

**What to build:** 8 波里前半仍是三种追击者，后半能看出种类在变：第 5–6 波出现少量冲锋者，第 7–8 波再出现少量射手；第 8 波两种都有，但权重低。变化来自新种类和可以略提高的快速追击者比例，不靠把单体伤害加回去。15 血角色不能被单下秒掉。

**Blocked by:** 02 一局变成 8 波 × 30 秒，HUD 看得到终点

**Status:** ready-for-agent

- [ ] 第 1–4 波场上只有追击者
- [ ] 第 5–6 波能遇到冲锋者，但不是满屏冲锋
- [ ] 第 7–8 波能遇到射手；第 8 波冲锋者和射手都会出现
- [ ] 15 血角色不会被冲锋或射击单下打空
- [ ] 敌人血伤没有借这张票重新按波次叠高
