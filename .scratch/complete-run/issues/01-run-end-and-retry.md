# 01: 死亡能结算、能再来一局

**What to build:** 玩家死了不再是角色蒸发、战斗还在空转。出现失败界面（失败、死于第几波、再来一局）。点再来回到选角色和武器（两者都要选才能开打），开局 20 金，装备清空，敌人不会带着上一局变肥的血伤。当前配置的最后一波（现在是第 5 波）倒计时结束且人还活着：直接胜利界面，不再进升级和商店。胜利也只有「胜利」和「再来一局」，不显示金币或击杀。结算时玩法暂停，虚拟摇杆隐藏。

**Blocked by:** None (can start immediately)

**Status:** done
